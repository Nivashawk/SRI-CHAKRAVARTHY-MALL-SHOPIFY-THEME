# Item codes (SKUs)

Customers can search these directly — Shopify's storefront search matches on
variant SKU, in both the header box and the full search page. The code is shown
on the product page via the stock `sku` block.

**These are placeholders (31001–31019), assigned alphabetically by handle.**
Replace with the client's real codes before launch.

To change them, edit the table and set each variant's `inventoryItem.sku`.
Note: `sku` is **not** a field on `ProductVariantsBulkInput` in current API
versions — it must be nested under `inventoryItem`, or the mutation fails with
"Field is not defined on ProductVariantsBulkInput".
